# Frontend - UTP Evalua

Frontend Angular standalone de la plataforma UTP Evalua.

## Estructura activa

```text
frontend/src/
  app/
    core/
    features/
    layout/
    shared/
  assets/
  main.ts
  styles.css
```

La aplicacion arranca desde `src/main.ts` con `bootstrapApplication` y usa rutas en `src/app/app.routes.ts`.

## Ejecutar

```powershell
npm install
npm start
```

Frontend: `http://localhost:4200`
